# RF_Observatory - Documentación

Para garantizar la supervivencia a largo plazo del ecosistema (Artículo X de la Constitución), la documentación de este repositorio se clasifica estrictamente en dos categorías:

## 1. Documentación Permanente (Directorio `docs/`)
Esta documentación define el "Qué" y el "Por qué" fundamental. Debe mantenerse siempre vigente y evolucionar cuidadosamente. Si el proyecto pasa de mano en mano durante 10 años, estos documentos dictarán las reglas del juego.
* **Constitución:** `00_CONSTITUTION.md`
* **Visión y Ecosistema:** `00_ProjectVision.md`, `01_EcosystemArchitecture.md`
* **Modelos y Protocolos:** `40_LaboratoryCaptureProtocol.md`, `41_CanonicalDataModel.md`
* **Epistemología:** `42_ScienceOfKnowledge.md`, `43_KnowledgePlatformParadigm.md`

## 2. Documentación Temporal (Directorio `project_management/`)
Esta documentación define el "Cuándo" y el "Quién". Sirve para gestionar el desarrollo del día a día, registrar decisiones puntuales y auditar el progreso. Es natural que quede obsoleta con el paso de los Sprints.
* **Roadmap & Casebook:** Planificación e historial de Decisiones Arquitectónicas (ADR / DA).
* **Epics & Tasks:** Bitácoras tácticas, reportes de tareas (`TASK_XXX_REPORT.md`), y auditorías.
