# BACKLOG ESTRATÉGICO (Congelado)

Este documento actúa como el "congelador" del proyecto. Contiene todas las visiones arquitectónicas y de producto que son técnica y científicamente brillantes, pero que **no contribuyen en absoluto al MVP Comercial actual**.

Ninguna de estas características se implementará, diseñará, ni documentará más hasta que SmartAccess sea capaz de registrar un control remoto real proveniente de RF_Laboratory.

## Ideas Congeladas
- **RF Knowledge Platform:** El concepto del Observatorio como un SaaS público/privado para múltiples clientes.
- **Knowledge Graph:** Transición de tablas relacionales a grafos de conocimiento.
- **Knowledge Reprocessor (DA-065):** El motor de reprocesamiento masivo de evidencia histórica.
- **RF Observatory SDK:** Librerías oficiales (NPM, PyPI) para integración de terceros.
- **RF Observatory CLI:** Herramientas de línea de comandos para importación y manipulación de capturas.
- **RF Observatory Replay:** Sistema de testing continuo inyectando capturas antiguas a nuevos algoritmos.
- **Benchmark Dataset:** Datasets curados para validación de Inteligencia Artificial.
- **Múltiples Tipos de Evidencia:** Imágenes de PCB, volcados de firmware, y audios (EPIC-002 suspendido).
